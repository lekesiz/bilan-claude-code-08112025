## 📞 TROUBLESHOOTING IF SOMETHING GOES WRONG

### Issue: AI Says "Spec is incomplete"
**Solution:** Specs are complete. AI might be confused. Show them exact section in COMPREHENSIVE_SPEC.

### Issue: AI Says "I need more details about X"
**Solution:** Send them the relevant section from COMPREHENSIVE_SPEC. That section has the details.

### Issue: Code doesn't compile
**Solution:** Ask AI to run through QUICK_START_GUIDE STEP 1-2 carefully. Usually it's a missing dependency.

### Issue: API returns 500 errors
**Solution:** Check backend logs. Likely Gemini API key issue. Verify `.env` file has correct key.

### Issue: Database not initializing
**Solution:** Delete `./data/bilan.db` and restart. Database will recreate.

### Issue: Frontend won't connect to backend
**Solution:** Verify both are running:
- Backend: `npm run server` listening on http://localhost:5000
- Frontend: `npm run client` listening on http://localhost:5173
